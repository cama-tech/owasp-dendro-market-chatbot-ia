# Laboratorio 4: Chatbot IA y OWASP

Aplicación local con matriz completa de escenarios vulnerables y seguros.

## Ejecutar

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

En Windows:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Abrir:

```text
http://127.0.0.1:5000
```

## Archivos importantes

- `app.py`
- `templates/index.html`
- `GUIA_ALUMNO.md`
- `GUIA_DOCENTE.md`
- `README.md`
